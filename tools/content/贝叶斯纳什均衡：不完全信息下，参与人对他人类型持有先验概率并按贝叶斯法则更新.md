# 一句话理解

**贝叶斯纳什均衡（Bayesian Nash Equilibrium, BNE）**：在不完全信息博弈中，每个参与人持有关于他人**类型**的先验，按贝叶斯法则更新为条件信念；策略是「类型 → 行动」的映射。策略组合是 BNE，当且仅当**对每个参与人、对其每一个可能类型**，该类型的行动在条件期望支付下是最优反应——即扩展博弈上的纳什均衡。【事实】

John C. Harsanyi（1967–68, *Management Science* 三部曲）把「不知道对方偏好」转成「自然抽类型 + 共同先验 + 不完全观察」，证明在一致性条件下存在 Bayes-等价的完全信息博弈；其上的 NE 即贝叶斯均衡。【事实】1994 年诺贝尔经济学奖授予 Harsanyi、Nash、Selten。【事实】

关键辨析：BNE 是**静态/策略型**不完全信息的解；动态不完全信息还要信念在路径上贝叶斯更新 + 序贯理性 → **完美贝叶斯均衡（PBE）**，是 BNE 的精炼。【事实】

# 这个领域到底是什么

研究的不是「猜对方心里想什么」的玄学，而是：在**支付/偏好不可完全观察**时，如何用类型空间、共同先验与条件期望，把互动压成可计算的最优反应不动点。

边界：

- **在界内**：类型、先验、条件信念、类型依赖策略、BNE 存在性、拍卖 IPV 对称均衡、与 PBE/机制设计（BIC）的接口。
- **在界外**：具体法庭证据规则细节、某只股票「庄家类型」的实时识别——除非压成「先验 + 信号 + 最优反应」的建模问题；动态离路径信念精炼属 PBE/序贯均衡另册。

## 最关键的一句话

> BNE 问的是：「给定我对你类型的信念，以及你每个类型会怎么做，我的每个类型还有没有更好的单方偏离？」——不是「事后结果是否公平」。

# 为什么值得研究

:::cards g3
### 它是真实世界的默认设定
拍卖、谈判、雇佣、监管、平台定价——你几乎从不完美知道对方偏好；完全信息 NE 只是特例。【事实】

### 它把「猜测」变成可检验结构
先验、似然、最优反应可分开质疑：错在分布、错在更新，还是错在目标函数。【分析】

### 它是机制设计的母语
贝叶斯激励相容（BIC）=「说真话」构成 BNE；Myerson 最优拍卖、收入等价都以 BNE 为解概念。【事实】
:::

:::note amber 最贵的一次误判
把「我对对方的点估计」当成共同知识，再套完全信息 NE。真实互动里对方也在对你的类型建模——漏掉这一层，出价与进入决策会系统性偏乐观。【分析】
:::

# 核心参与者

:::cards g3
### 理论奠基者
Harsanyi（不完全信息）；Nash（均衡母体）；Selten（精炼）；Myerson（机制/拍卖）；Aumann（共同知识与先验争论）。【事实】

### 应用解释者
拍卖行与广告竞价、频谱与国债发行、产业组织进入、保险与信贷逆向选择、多智能体学习。【分析】

### 你自己
竞标、谈判开价、投简历、选是否进入市场——只要对方有私人类型，你就在玩贝叶斯博弈。【推论】
:::

# 核心变量

| 变量 | 含义 | 为什么重要 |
|---|---|---|
| 类型 \(\theta_i\) | 私人偏好/成本/估值 | 策略定义域；漏类型 = 漏半个博弈 |
| 共同先验 \(p(\theta)\) | 类型联合分布 | 分歧只能来自信息差（CPA 下） |
| 条件信念 | \(p(\theta_{-i}\mid\theta_i)\) | 决定条件期望支付 |
| 策略 \(s_i(\cdot)\) | 类型→行动（或混合） | BNE 要对**每个** \(\theta_i\) 成立 |
| 信号精度 | 似然比 / 噪声 | 更新幅度；决定分离/混同 |
| 相关结构 | 独立 vs 关联类型 | IPV 简化 vs 赢家诅咒 |
| 风险偏好 | 风险中性假设 | 收入等价等定理的前提 |

# 隐藏关系

:::cards g2
### 策略是函数，不是一次动作
学生最常见错误：只优化「我现在这个类型」而忘记策略必须对**所有**类型自洽。【事实】

### 共同先验 ≠ 信念正确到现实
CPA 下信念彼此一致（分歧=信息差）；先验本身仍可「错」——模型外的分布不保证。【分析】

### BNE 可被相关价值击穿
IPV 下漂亮的压价公式；共同价值下忽略「我赢了 ⇒ 别人信号更差」会系统性亏损（赢家诅咒）。【事实】
:::

# 系统运行机制

贝叶斯博弈五元组：参与人集合 \(I\)；行动集 \(A_i\)；类型集 \(\Theta_i\)；支付 \(u_i(a,\theta)\)；先验 \(p\)。【事实】

纯策略 BNE：对每个 \(i\)、每个 \(\theta_i\)，

\[
s_i(\theta_i)\in\arg\max_{a_i}\sum_{\theta_{-i}}p(\theta_{-i}\mid\theta_i)\,u_i\bigl(a_i,s_{-i}(\theta_{-i}),\theta_i,\theta_{-i}\bigr).
\]

有限贝叶斯博弈存在（可能混合）BNE——证明路径与有限 NE 同构：把「类型→行动」当成扩展纯策略。【事实】

# 常见认知陷阱

:::details 陷阱 1 · 把策略当成「这一次的动作」
BNE 要求整张类型→行动表自洽。只对自己当前类型算最优，常得到假均衡。
:::

:::details 陷阱 2 · 用点估计替代分布
「我觉得对方成本大概是 20」≠ 对 \(p(\theta)\) 积分。尾部类型往往主导最优反应。
:::

:::details 陷阱 3 · 混淆不完全信息与不完美信息
不完全=不知道偏好/支付；不完美=不知道历史行动。Harsanyi 把前者变成带自然行动的后者。【事实】
:::

:::details 陷阱 4 · 把 BNE 直接当 PBE
静态密封报价可用 BNE；谈判树、信号发送要检查离路径信念。【事实】
:::

:::details 陷阱 5 · 忽略赢家诅咒
共同价值拍卖里，以「赢得拍品」为条件后，估值应下调；朴素 BNE 会买贵。【事实】
:::

:::details 陷阱 6 · 假定独立同分布永远成立
合谋、共同冲击、关联信号破坏 IPV；公式 \(b=(n-1)v/n\) 不再适用。【分析】
:::

:::details 陷阱 7 · 共同先验教条化
CPA 便于分析；实证与认识论上「异质先验」常见。先做敏感性，再谈唯一性。【分析】
:::

:::details 陷阱 8 · 事后理性化当均衡
「结果看起来双方都没后悔」可能是选择偏差；均衡是事前条件期望概念。
:::

:::details 陷阱 9 · 混同「贝叶斯更新」与「贝叶斯均衡」
更新只是信念模块；均衡还要求策略相互最优。会更新≠已达 BNE。
:::

:::details 陷阱 10 · 把收入等价当成普适
RET 要风险中性、IPV、对称、效率配置等；格式一变，卖家收入可分叉。【事实】
:::

# 从理论到行动

1. **命名类型**：对方至少两种（强/弱、高/低估值）。
2. **写先验**：用频率或主观概率，并记录来源。
3. **写策略表**：每个类型会做什么（含你自己）。
4. **验每个类型**：给定他人策略，该类型能否单方改进。
5. **对照完全信息**：若类型公开，NE 会怎样——差即信息的影子价格。
6. **选干预**：改披露、改保留价、改合同菜单，而不是只改「态度」。

# 反事实模拟

若共同先验改为异质先验，BNE 的认知基础变弱，但仍可定义「各自信念下的相互最优」——解释力下降。【分析】

若一价拍卖从 IPV 改为共同价值，对称增压公式失效，需胜者诅咒修正。【事实】

若把进入博弈的「强硬」先验从 0.2 推到 0.7，进入方的条件期望从正变负，BNE 从「进入」翻转为「不进入」。【推论】

## 可调模型 1 · 进入威慑：强硬先验 α

在位者类型：强硬（概率 \(\alpha\)）或软弱（\(1-\alpha\)）。潜在进入者选进入/不进入。支付约定：不进入时进入者得 0、在位者得 2；进入遇强硬得 −1，遇软弱得 +1（在位者进入后均得 1）。则

\[
EU(\text{进入})=-\alpha+(1-\alpha)=1-2\alpha.
\]

进入当且仅当 \(\alpha\le 1/2\)。默认 \(\alpha=0.30\) → \(EU=0.40\) → **进入**；强硬总战、软弱总容纳构成类型策略 BNE 的一支。【事实】

## 可调模型 2 · 一价密封拍卖：对称 IPV 压价

\[

## 可调模型 3 · 贝叶斯更新：先验 × 信号精度

\[
\text{后验}=\frac{\pi q}{\pi q+(1-\pi)(1-q)}.
\]

默认 \(\pi=0.30,q=0.80\) → 后验 \(\approx 0.632\)。这是 BNE 的信念积木：策略最优建立在正确的条件概率上。【事实】

## 可调模型 4 · 不完全信息古诺：未知对手成本

逆需求 \(P=a-(q_1+q_2)\)，你的成本 \(c_1\) 公开；对手成本 \(c_L\)（概率 \(p\)）或 \(c_H\)。BNE：

\[
q_1^*=\frac{a-2c_1+\mathbb{E}[c_2]}{3},\quad q_2(c)=\frac{a-c-q_1^*}{2}.
\]

默认 \(a=100,c_1=20,c_L=10,c_H=40,p=0.50\) → \(\mathbb{E}[c_2]=25\)，\(q_1^*\approx 28.33\)，\(q_{2L}\approx 30.83\)，\(q_{2H}\approx 15.83\)，期望价格 \(\approx 48.33\)。【推论】

# 10 个核心模型

1. **Harsanyi 变换**：不完全信息 ↔ Bayes 等价博弈。【事实】
