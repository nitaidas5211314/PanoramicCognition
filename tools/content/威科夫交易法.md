# 一句话理解

威科夫交易法只做一件事：**把「复合人在干什么」的读图结论，翻译成一份能在盘前写完、盘中执行、盘后复盘的交易计划。**

它与「威科夫操盘法」的分工可以这样记：

| 维度 | 威科夫操盘法 | 威科夫交易法（本手册） |
|---|---|---|
| 核心问题 | 图上发生了什么？ | 我该怎么做？ |
| 输出物 | 结构标签、事件序列 | 五步法清单、入场类型、止损、仓位、证伪条件 |
| 时间尺度 | 周线定结构、日线读事件 | 日线定计划、小时/分时找执行点 |
| 成败标准 | 读得对不对 | **计划有没有被执行、统计期望值是否为正** |

三根支柱不变——供求律、因果律、努力与结果律——但本手册把它们**全部落到 if-then 规则**：

1. **五步法**：趋势 → 相对强度 → 因果空间 → 赔率 → 止损，任一项不过关就不下单。
2. **三态规则**：交易区间只试探、拉升段才标准仓、下跌段多头风险预算归零。
3. **入场路径**：Spring 小仓潜伏、**LPS 回踩是主路径**、SOS 当日追价通常期望最低。

> 【分析】Richard Wyckoff 在 1931–1932 年的课程里把「Tape Reading and Active Trading」与结构分析并列——**读图是输入，交易纪律是输出**。只学形态而不写计划，等于只学了输入端。

# 这个领域到底是什么

## 一句话边界

威科夫交易法研究的**不是「明天涨不涨」，而是「在已知结构下，哪一笔交易的风险回报结构值得占用我的风险预算」**。

## 用 15 个问题划定边界

| 问题 | 答案 |
|---|---|
| 研究什么 | 把威科夫结构转化为**可执行的交易决策规则** |
| 边界在哪 | 只管「怎么做」，不重复解释「怎么读」——读图见姊妹手册《威科夫操盘法》 |
| 核心对象 | **交易计划**（含证伪条件），而非单次预测 |
| 参与者 | 你（执行者）、复合人（对手方模型）、跟随盘（流动性来源） |
| 核心变量 | 趋势方向、相对强度、因果宽度、赔率、止损距离、摩擦成本 |
| 可观察 | 五步法各分项是否达标、入场类型、实际成交滑点 |
| 不可观察但可推断 | 复合人库存是否建完、是否处于 Phase C |
| 谁影响谁 | 结构判断 → 计划 → 执行 → 盈亏 → 下一笔计划的置信度 |
| 确定因果 | 止损距离定死 → 仓位反推 → 单笔最大亏损封顶 |
| 只是相关 | 「五步法全过」与「盈利」——相关，不是充分条件 |
| 表层现象 | Spring、SOS、LPS 等标签 |
| 底层机制 | 风险预算在有限机会间的分配 |
| 反馈 | 连赢 → 放大仓位冲动；连亏 → 跳过清单 |
| 时间延迟 | 计划写在盘前，验证在数周至数月后 |
| 正负反馈 | 纪律 → 可统计 → 改进规则；冲动 → 不可复盘 → 永远停在故事层 |

## 威科夫五步法的交易含义

【事实】Wyckoff Analytics 与 Stock Market Institute 传承的五步法，在中文圈常被简化为「先看大盘」——**完整版是五项硬过滤**：

| 步骤 | 交易层问题 | 不过关的后果 |
|---|---|---|
| 1 趋势 | 大盘与个股是否处在**值得做多/做空**的环境？ | 逆势交易，结构再漂亮也是逆风 |
| 2 相对强度 | 同板块里是否选到**更强/更弱**的那只？ | 选对方向但选错标的，浪费因果 |
| 3 因果（点数图） | 横盘宽度是否撑起**目标空间**？ | 赔率不够，不做 |
| 4 赔率 | (目标 − 入场) ÷ (入场 − 止损) 是否 ≥ 2？ | 数学上不值得下注 |
| 5 止损 | 止损是否放在**结构性位置**之外？ | 被正常波动扫出，无法统计 |

# 为什么值得研究

## 四个理由

:::cards g2
### 它把「感觉」变成「清单」
飞行员起飞前有检查单；威科夫交易者在下单前有五步法。**清单的价值不是保证成功，而是保证失败可归类**——是趋势错了、赔率错了，还是执行错了。

### 它区分三种市场状态的交易规则
很多人用同一套仓位对待横盘与趋势。威科夫明确要求：**区间里试探、趋势里持有、下跌里空仓**——这是仓位管理的第一性原理。

### 它把 LPS 设为默认入场
【分析】突破日（SOS）与回踩日（LPS）在 K 线上往往无法区分；但**突破后行为**可以——SOS 后有缩量回踩，Upthrust 后往往直接放量下跌。**等 LPS 是整套方法里期望值最高的修正。**

### 它的失败可以被统计
不能机械回测整个框架，但**你的每一笔计划可以记录、可以算期望**。30 笔之后你就会知道自己的 Spring 命中率，而不是教材里的数字。
:::

## 必须先接受的三个局限

- **右端模糊**。【分析】Backtesting Arena 2026 年对 Spring 的预注册检验：在 BTC/ETH 等 10 个品种上，**机械 Spring 规则在扣费后未显著跑赢基准**，且与 RSI(14) 上穿 30 的 placebo 相当。【待验证】
- **标签不可前视**。Phase C 的 Spring/UTAD 往往在事后才清晰；**交易法要求用「证伪条件」代替「确认标签」**。
- **摩擦吃掉边缘**。【推论】若信号真实超额约 +6.3 pp（40 日），往返成本 0.4% 约吃掉 0.4 pp——**高频试错在威科夫框架里尤其危险**。

:::note amber 一句话定性
威科夫交易法是一套**风险预算分配系统**，披着技术分析的外衣。**不会选时的人学形态，会选时的人学仓位与止损。**
:::

# 核心概念地图

## 交易系统的四大模块

:::cards g2
### 模块 A · 环境过滤（五步法 1–2）
大盘趋势 + 个股相对强度。不做逆势、不做板块里最弱的「吸筹故事」。

### 模块 B · 空间过滤（五步法 3–4）
P&F 因果宽度 → 目标价 → 赔率。目标价传统打七折（×0.7）后再算赔率。

### 模块 C · 触发与执行（事件 + 入场路径）
Spring / SOS / LPS 三条路径，**默认 LPS**。

### 模块 D · 风险封顶（五步法 5 + 仓位）
结构性止损 → 反推股数。**仓位由止损距离决定，不由「有多看好」决定。**
:::

## 三种入场路径对照

| 路径 | 典型位置 | 胜率（示意） | 平均赢/输 | 摩擦后期望 E | 适用仓位 |
|---|---|---|---|---|---|
| Spring 潜伏 | Phase C 假跌破 | 48% | +12% / −5% | **+2.96%** | 试探（风险预算 ×0.5） |
| **LPS 回踩** | SOS 后缩量回踩 | 58% | +9% / −4% | **+3.44%** | 标准仓 |
| SOS 追突破 | 突破当日收盘 | 52% | +7% / −6% | **+0.36%** | 原则上不做 |

（期望公式：E = p·W − (1−p)·L − 2×摩擦；上表摩擦取 0.10% / 0.05% / 0.20% 单程示意。）

## 跨域同构

| 威科夫交易概念 | 其他领域的同名结构 |
|---|---|
| 五步法清单 | 航空检查单 · 外科手术 Time-out |
| 交易区间试探仓 | 多臂老虎机「探索」阶段 · 扑克大量弃牌 |

# 核心变量

| 变量 | 交易法中的用法 | 阈值示例（需自行验证） |
|---|---|---|
| 趋势分 | 五步法第 1 项，0–5 分 | 指数在 200 日均线之上 = 3 分以上 |
| 相对强度分 | 五步法第 2 项 | 板块内涨幅排名前 30% = 3 分以上 |

# 隐藏关系

## 隐藏关系一：基准胜率不是 50%

【待验证】公开平台称威科夫吸筹信号 40 日胜率 **65.1%**；但随机做多 40 日基准约 **58.76%**（μ=10%、σ=18%），真实超额约 **+6.3 pp**。扣往返成本 0.4% 后约 **+5.9 pp**。【推论】

牛市里（μ=20%、σ=12%）随机 40 日胜率 **74.7%**——**表面 65.1% 的「高胜率」可能跑输不动**。

## 隐藏关系二：入场路径决定期望，而非形态标签

同一吸筹结构下：
- Spring E ≈ **+2.96%**
- LPS E ≈ **+3.44%**
- SOS 追 E ≈ **+0.36%**

**「读对了」但「进错了」，期望仍可能接近零。**

## 隐藏关系三：半凯利与全凯利的差距

胜率 55%、盈亏比 2.1:1 时，凯利 f* ≈ **33.6%**，半凯利 **16.8%**。【推论】威科夫强调止损，本质是**把 f* 压到可生存区间**——全凯利在真实连亏中会爆仓。

## 磁带解读（Tape Reading）的现代等价物

【事实】Wyckoff 1932 年《Tape Reading and Active Trading》强调：**买卖波（Buying/Selling Waves）与即时趋势**决定日内进出时机；结构分析定「做不做」，磁带定「何时下单」。

现代映射：Footprint / 订单流热力图 / VWAP 回踩——**把「努力与结果」从日线下沉到分钟级**。

# 常见认知陷阱

:::details 陷阱 1 · 把「会读图」当成「会交易」
**症状**：能标出 Spring，但从未写过止损价。

**对冲**：五步法第 5 项强制打分；&lt; 3 分禁止下单。
:::

:::details 陷阱 2 · SOS 当日 FOMO
**症状**：「再不上车来不及了」。

**机制**：突破日滑点大、赔率差；期望仅 **+0.36%** 量级。

**对冲**：规则写死——SOS 日只观察，入场权给 LPS。
:::

:::details 陷阱 3 · 区间里用满仓
**症状**：Spring 后一次打满。

**机制**：Phase B 可延续数周，满仓机会成本与心理压力大。

**对冲**：三态规则：区间风险预算 ×0.5。
:::

:::details 陷阱 4 · 止损设在「大家都看得见」的位置
**症状**：止损正好在 Spring 低点上。

**机制**：复合人知道止损簇在哪；**止损应在结构外留余量**。
:::

:::details 陷阱 5 · 用胜率代替赔率
**症状**：「我 10 次对 7 次」但平均亏的比赚的多。

**对冲**：每笔算盈亏平衡胜率 p* = L÷(W+L)；赔率 &lt; 2 时 p* &gt; 33%。
:::

:::details 陷阱 6 · 忽视基准漂移
**症状**：「40 日胜率 65%」觉得很牛。

**机制**：随机做多 40 日基准 **58.76%**；牛市更高。

**对冲**：任何胜率报告必须带「对照基准」。
:::

:::details 陷阱 7 · 不记摩擦
**症状**：回测不含佣金滑点。

**机制**：薄边缘策略被 0.2%–0.5% 往返磨没。

**对冲**：期望公式减去 2×摩擦。
:::

:::details 陷阱 8 · 持仓后重读图
**症状**：同一区间越看越像吸筹。

**机制**：L9 层偏差。

**对冲**：每周一次「空仓重评」。
:::

:::details 陷阱 9 · 把 Spring 回测当圣杯
**症状**：引用「13,000 信号胜率」。

**机制**：【待验证】预注册 Spring 检验未显著优于 placebo；【分析】口径与主观标签不可比。

**对冲**：只信你自己日志里的数字。
:::

:::details 陷阱 10 · 逆势抄底用威科夫包装
**症状**：大盘 Markdown 仍找「吸筹」。

**机制**：五步法第 1 项应否决。

**对冲**：下跌段多头风险预算 = 0。
:::

:::details 陷阱 11 · 目标价不打折
**症状**：P&F 目标当必达价。

**机制**：【待验证】民生证券称起始空间 &gt;50% 时误差上升，需约 **30%** 保守修正。

**对冲**：目标 ×0.7 后再算赔率。
:::

:::details 陷阱 12 · 学清单却不执行
**症状**：清单全勾，盘中全破。

**机制**：威科夫原意：自我控制与记录同技术并重。

**对冲**：违反规则的交易不计入统计样本——先保纪律。
:::

# 反事实模拟

:::tabs
@@情景 A：五步法全过，但追了 SOS
**结果**：入场价比 LPS 高 3%–5%，止损更远，赔率从 6.7 降到 2 以下；摩擦后期望接近 **+0.36%**。

**教训**：过滤正确、执行错误，仍会接近零期望。
@@情景 B：LPS 完美，大盘一周跌 8%
**结果**：个股 LPS 被击穿，止损执行，小亏封顶。

**教训**：五步法第 1 项是一票否决；**计划正确 + 环境错误 = 小亏，不是大亏**。
@@情景 C：Spring 试探后横盘 60 日
**结果**：无 SOS、无 LPS，资金占用，机会成本巨大。

**教训**：证伪时间上限（如 20 日）必须写进计划。
@@情景 D：连续 5 笔按计划止损
**结果**：账户 −5%（每笔 1%），心态崩溃，第 6 笔打破规则重仓。

**教训**：L7 技能（规则违反率）比 L4（会认形态）更决定生死。
:::

# 30 分钟最小实践

## 今天就做：给关注标的写「一页交易计划」

**成本**：0 元，30 分钟。

**步骤**：

1. **（5 分）** 选一个你已关注的标的。
2. **（10 分）** 用工具 1 打五步法五项分；&lt;3.5 或任一项 &lt;2 → 写「本标的不做」，练习结束（这也是有效产出）。
3. **（10 分）** 若放行：填模板——市场态、LPS 条件、入场/止损/目标、证伪、用工具 4 算股数。
4. **（5 分）** 用工具 3 对比：若被迫 SOS 追价，期望下降多少？

**产出**：一张可存档的一页计划 + 五步法得分。
