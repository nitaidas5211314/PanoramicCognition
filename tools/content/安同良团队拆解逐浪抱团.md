# 一句话理解

**逐浪抱团**是南京大学商学院安同良教授团队对 A 股量化交易第二种典型形态的命名：上涨趋势形成时，**同质化算法批量追入助涨**；一旦股价跌破均线或动量反转，**同步触发止损**，造成上涨加速、下跌踩踏——散户往往在**信心最足、仓位最重**时承接反转风险。【分析】

与「坟包收割」的慢刀阴跌不同，逐浪抱团是**快波**：借热点与趋势放大波动，再靠策略同质性在拐点「一起跑」。学它的方式，是学「怎么识别双相结构」，而不是学「怎么抓下一波热点」。

# 这个领域到底是什么

## 边界：研究什么、不研究什么

| 研究 | 不研究 |
|---|---|
| 趋势段**助涨**与反转段**同步卖**的可观测特征 | 明天哪条赛道会涨停 |
| 策略**同质化**如何放大正/负反馈 | 某个私募是否「恶意做局」 |
| 热点、散户情绪与量化信号的**叠加机制** | 消灭动量策略或全面禁量化 |
| 散户如何**识别退潮**、控制追涨仓位 | 保证靠「反量化」稳定盈利 |

## 十五个问题：先建世界模型

| 问题 | 答案 |
|---|---|
| 研究什么 | 同质化量化如何在趋势中放大波动，并在拐点同步退出 |
| 边界在哪 | 到「价量+板块+策略结构」可观测层；个体动机需另证 |
| 核心对象 | 趋势助涨段、均线/动量触发线、同步止损链 |
| 参与者 | 量化私募、游资、散户、券商、交易所、监管层、学者 |
| 核心变量 | 策略同质性、板块热度、散户情绪、量化成交占比、均线偏离 |
| 可观察 | 板块涨停家数、量能、论坛关键词、相对强度、回撤同步性 |
| 不可观察但可推断 | 因子权重、止损阈值分布、多产品协同 |
| 谁影响谁 | 热点 → 量化信号 → 价格 → 技术确认 → 散户追涨 → 流动性 → 再反馈 |
| 确定因果 | 策略同质 ↑ → 拐点卖压同步 ↑【推论·结构】 |
| 只是相关 | 「板块暴涨后暴跌」与「量化主导」——也可来自基本面证伪 |
| 表层现象 | 热点轮动、龙头连板、均线多头、退潮 A 字杀 |
| 底层机制 | 动量/趋势因子趋同 + 止损规则相似 → 正反馈踩踏 |
| 反馈 | 助涨吸引更多量化模仿（正反馈）；同步止损加深下跌（正反馈） |
| 时间延迟 | 助涨段数日至数周；踩踏常在**跌破均线后 1–2 周**集中 |
| 正负反馈 | 监管降频/差异化收费 → 策略分化 → 同步性下降（负反馈） |

| 概念 | 问什么 | 与逐浪的关系 |
|---|---|---|

# 为什么值得研究

## 四个理由

:::cards g2
### 它解释「差公司也被推涨」
团队指出：业绩不佳但**沾热点**的标的，可能被量化「一波波推上去」——价格与基本面短期脱钩。【分析】这比单票阴谋论更接近**系统行为**。

### 它连接「个体理性、集体非理性」
央广评论引用团队研究：每家机构止损合规，**集体同时减仓**却挤压流动性、伤害广大投资者——典型的合成谬误。【分析】

### 它逼你对「趋势胜率」做基准对照
A 股有正漂移：μ=10%、σ=18%、T=40 日时随机做多基准胜率 **58.76%**——「40 日胜率 65%」的真实超额仅 **6.3 pp**（见 §20 漂移剥离器）。【推论·公式】

### 它给出可操作的退潮识别框架
即便不认同全部因果，仍可学会：**板块极端热度时减仓、跌破关键均线不补仓、把论坛狂热当反向指标**——零成本可验证。
:::

## 也必须先说清楚：争议在哪里

- **量化行业反驳**：趋势跟踪提供流动性、价格发现，不能把所有波动归因「收割」。【分析】
- **因果识别困难**：板块退潮可能来自政策、业绩、资金利率，未必是量化同步卖。【推论】
- **NLP 读舆情**：媒体报道称量化可能分析股吧关键词【待验证】——缺乏公开可复现实证。
- **政策建议≠现行法**：15 笔/秒门槛仍是建议，现行 **300 笔/秒**【事实】。

:::note amber 一句话定性
逐浪抱团是**高质量的趋势风险叙事 + 中等质量的因果证据**。价值在「识别双相结构」，不在「预测下一热点」。
:::

# 核心概念地图

## 逐浪双阶段

:::cards g3
### 阶段一 · 逐浪助涨
趋势形成后，算法批量追入。动量、波动率、流动性因子同时亮灯，**波动被放大**。【分析】

### 阶段二 · 抱团顶峰
散户论坛「加仓」「涨停」关键词集中【待验证】，技术均线完美——**信心与仓位同步见顶**。【分析】

### 阶段三 · 同步踩踏
跌破均线或动量反转，同质化模型**同步止损**。央广所称「个体理性、集体非理性」在此兑现。【分析】
:::

## 团队归纳的三套手法（对照）

| 手法 | 时间尺度 | 核心机制 |
|---|---|---|
| **逐浪抱团** | 中（数日至数周） | 同质趋势策略助涨 → 同步止损踩踏 |
| 坟包收割 | 长（20–30 日阴跌） | 假突破 → 慢出货 |
| 精准狙击 | 短（涨停日） | 诱多 + 融券 + T+1 锁仓 |

## 跨域同构

| 本领域 | 同构领域 | 共享结构 |
|---|---|---|
| 同步止损 | 银行挤兑 | 每家合规退出 → 系统流动性崩溃 |
| 助涨段 | 声学共振 | 同频叠加 → 振幅指数放大 |
| 热点逐浪 | 流行病 R₀>1 | 感染（跟风）速度超过恢复（退潮） |
| 策略同质 | 生态系统单一化 | 多样性下降 → 冲击脆弱性上升 |
| 漂移基准 | 临床试验对照组 | 不把自然好转当成疗效 |

# 隐藏关系

1. **逐浪与坟包常串联**：热点退潮后，个别票可能转入「坟包式阴跌」——同一生态的不同相位。【分析】
2. **好公司也可能被错杀**：同步止损不区分基本面，流动性好的龙头同样可能被同质卖单波及。【推论】
3. **「主线永远」是 L9 陷阱**：板块叙事越完美，L5 同质性往往越高——危险在**一致性预期**。
4. **流动性幻觉**：助涨段量化「提供流动性」，退潮段央广指出流动性**直接消失**——功能不对称。【分析】
5. **跨域同构：收益私有化、损失社会化**：个体机构赚取趋势段收益，尾部踩踏由全市场承担。【分析】

# 常见认知陷阱

:::details 1. 「这是国策级主线，不会退潮」
板块叙事越宏大，L5 同质性往往越高——**一致性预期**是逐浪最危险的燃料。【分析】
:::

:::details 2. 「涨得快说明基本面好」
团队反例：业绩不佳但沾热点仍可被推高。【分析】
:::

:::details 3. 「量化提供了流动性，对我有利」
央广指出：最需要流动性时量化流动性**消失**——功能不对称。【分析】
:::

:::details 4. 把趋势胜率当能力
μ=10%、σ=18%、T=40 时基准胜率 **58.76%**——65% 并不惊人。【推论】
:::

:::details 5. 「跌破均线是洗盘」
逐浪第二段的核心正是**同步止损**，不是洗盘。【分析】
:::

:::details 6. 追逐每一个热点
换手越高，越易落在 L9 最高仓位点。【推论】
:::

:::details 7. 把媒体报道当铁案
37.6%、2.1 万、NLP 读股吧等均为【待验证】或【分析】。
:::

:::details 8. 忽视机构间互搏
量化也互相踩踏——不是「量化 vs 散户」二人转。【推论】
:::

:::details 9. 政策建议当已落地
15 笔/秒非现行标准。【事实】
:::

:::details 10. 「反着做量化就能赢」
无公开稳定信号支持。【假设】
:::

:::details 11. 只看龙头不看板块量能
板块量能萎缩是退潮领先指标。【推论】
:::

:::details 12. 幸存者偏差看量化收益
报道样本未必含清算机构。【待验证】
:::

# 30 分钟最小实践

**目标**：对你正在关注的一个板块，完成「逐浪退潮体检表」。

1. **5 分钟**：查近 20 日板块涨停家数、成交额占全市场比例——是否在历史高位？
2. **5 分钟**：看板块龙头与指数相对 MA20——是否仍站上？
3. **5 分钟**：用热点温度计输入自评热度/情绪（0–100），读风险指数。
4. **10 分钟**：写三条规则——(a) 热度分位 >X 时最大仓位；(b) 破 MA20 如何减仓；(c) 什么证据出现则承认「主线结束」。
5. **5 分钟**：把团队引用的 NLP、37.6% 等标【待验证】，写一句待查来源。

**产出**：一张可存档的体检表 + 三条规则。**成本 ≈ 0**。
