# 一句话理解

**委托—代理问题**：一方（委托人）想让另一方（代理人）按自己的目标行动，但信息不对称——隐藏行动或隐藏类型——使「直接下令」不可行。委托人只能设计合同，在两条硬约束下最大化自己的期望收益：【事实】

1. **激励相容（IC, Incentive Compatibility）**：代理人在合同下的最优选择，恰好是委托人想要的行动/报告；
2. **参与约束（IR / PC, Individual Rationality / Participation）**：代理人 voluntarily 签约，期望效用不低于外部机会 \(\underline{u}\)。

机制设计把博弈论「反过来用」：不预测给定规则下的均衡，而是**选规则**，使均衡结果落在目标集合里。Myerson（1982）启示原理：最优机制可限缩为「直接、激励相容」机制。【事实】

# 这个领域到底是什么

研究的不是「怎么管人」，而是：**在信息约束下，哪些目标可被实施，实施它们的最小代价是什么**。

边界：

- **在界内**：IC、IR、信息租金、代理成本、有限责任、启示原理、菜单/直接机制。
- **在界外**：某次绩效面谈话术、某份期权行权日选择——除非压成「哪条约束绑定、租金多大」。

与相邻主题的分工：道德风险专讲「签约后隐藏行动」；逆向选择专讲「签约前隐藏类型」；本手册专讲二者共用的**约束骨架**与机制设计表述。【分析】

# 为什么值得研究

:::cards g3
### 它是组织设计的「操作系统」
薪酬、股权、对赌、外包 SLA、监管沙盒——全是同一套约束优化的实例化。【分析】

### 它把「公平感」翻成可算账的量
信息租金、风险贴水、代理成本：可比较、可权衡，而不是口号。【事实】

### 它连接 2016 诺奖与日常合同
Hart / Holmström 的合同理论与 Myerson 的机制设计，在 IC/IR 上交汇。【事实】
:::

:::note amber 最贵的一次误判
把「代理人不愿签」当成激励不够（加 IC），其实是保留效用上升（应调 IR）；或反过来，用抬底薪代替拉开绩效差——IC 仍松弛，努力不变。【分析】
:::

# 核心参与者

| 角色 | 目标 | 信息位置 | 典型工具 |
|---|---|---|---|
| 委托人 | max 期望净收益 / 社会福利 | 通常无私人信息（筛选设定） | 合同菜单、支付规则、监控 |
| 代理人 | max 期望效用 − 努力成本 | 持有行动或类型 | 选择努力/报告/是否参与 |
| 外部市场 | 标定 \(\underline{u}\) | 机会成本 | 跳槽、另签、另投 |
| 监管 / 审计 | 降低可验证成本、保护第三方 | 强制披露 | 信披、清理对赌、激励办法 |

Jensen–Meckling（1976）：代理成本 = 监控成本 + 担保成本 + 剩余损失。【事实】

# 核心变量

| 变量 | 符号 | 系统作用 |
|---|---|---|
| 保留效用 | \(\underline{u}\) | 钉住 IR；市场紧则 IR 更易绑定 |
| 激励相容隙 | \(\Delta\) IC slack | >0 表示激励「过强」或可降成本 |
| 似然比 | \(f_a/f\) | 决定最优支付对信号的敏感度 |
| 激励强度 | \(\beta\) | 线性合同中努力与风险的折中 |
| 有限责任下界 | \(w \ge 0\) | 可使 IR 松弛、留下租金 |
| 类型差 | \(\theta_H-\theta_L\) | 决定信息租金规模 |
| 监控精度 | \(m\) | 用观测替代金钱激励 |

因果链（压缩版）：

1. 隐藏信息/行动 ⇒ 不能强制「理想行动」；
2. 必须用支付差制造 IC；
3. 支付差带来风险或租金；
4. IR 保证人还在桌上；
5. 最优往往是**次优**——代理成本或信息租金 > 0。【事实】

# 隐藏关系

:::cards g2
### IC 松弛 ≠ 好事
过度激励浪费风险分担；多任务下强激励某一维会挤出其他维（Holmström–Milgrom 1991）。【事实】

### IR 松弛 = 有限责任下的租金
\(w\ge 0\) 时，满足 IC 的合同可能自动给代理人超额效用——这是租金，不是「大方」。【分析】

### 启示原理的隐藏代价
「直接机制够了」不代表实施成本低；复杂间接机制可能在有限沟通下更便宜。【待验证】

### 相对绩效的隐藏用途
同事/同行产出进入合同，当且仅当它改变似然比（充分统计量定理）。【事实】
:::

# 系统运行机制

标准程序（Grossman–Hart 两步法）：【事实】

1. **对每个候选行动 \(a\)**：求实施 \(a\) 的最小期望工资（s.t. IC、IR）；
2. **在行动集合上**：选使「期望产出 − 实施成本」最大的 \(a^*\)；
3. **读乘子**：IR 绑定 → 市场紧或保险充分；IC 绑定 → 激励稀缺；有限责任绑定 → 租金与扭曲并存。

道德风险默认参数（\(u=\sqrt{w}\)，\(p_H=0.8\)，\(p_L=0.4\)，\(c_H=0.1\)，\(\underline{u}=0.1\)）：最优实施高努力时 \(w(1)=0.0625\)，\(w(0)=0\)，期望工资 0.05；完全信息下固定工资 0.04；**代理成本 0.01**。【推论】

# 利益与激励

| 主体 | 想要什么 | 与 IC/IR 的冲突点 |
|---|---|---|
| 股东 | 长期价值、可控风险 | 强股权激励可能扭曲风险选择 |
| 经理 | 薪酬、控制权、声誉 | 偏好保险（松 IC）或租金（松 IR） |
| 员工 | 稳定收入 + 公平感 | 相对绩效伤协作 |
| 投资人（对赌） | 估值保护、退出 | 市值挂钩条款 vs 监管清理 |
| 监管 | 市场秩序、中小投资者 | 限制某些「激励工具」本身 |

:::note purple 激励相容的政治学
「激励相容」常被口号化。严格含义是：**给定他人策略，真话/目标行动是最佳反应**——不是「大家感觉公平」。【分析】
:::

# 常见认知陷阱

:::details 1. 「高薪 = 激励到位」
底薪抬 IR，斜率才抬 IC。只涨底薪，努力不变。【分析】
:::

:::details 2. 「激励越强越好」
风险厌恶下最优 \(\beta^*<1\)；多任务下强激励可毁灭质量。【事实】
:::

:::details 3. 「公平分成 50/50」
最优分成由风险与激励权衡决定，不是对称直觉。【推论】
:::

:::details 4. 「对赌一定能对齐」
对赌是 IC 工具，但若发行人作当事人或挂钩市值，监管可强制清理——机制在法域不可实施。【事实】
:::

:::details 5. 「运气好也该奖」
充分统计量：共同冲击信息应被过滤；奖运气是次优。【事实】
:::

:::details 6. 「IR 永远绑定」
有限责任下 IR 常松弛，代理人拿走租金。【事实】
:::

:::details 7. 「一阶方法总可用」
FOA 需 MLRP+CDFC 等；失效时用 Grossman–Hart 有限行动法。【事实】
:::

:::details 8. 「复杂合同一定更好」
沟通、执行、诉讼成本会使简单线性合同胜出（HM 1987 近似）。【分析】
:::

:::details 9. 「代理人偷懒 = 品德差」
在错误合同下，偷懒是均衡最优反应。【分析】
:::

:::details 10. 「机制设计 = 拍卖理论」
拍卖是应用；骨架仍是 IC+IR（+预算平衡等）。【事实】
:::

# 从抽象到现实

| 抽象 | 现实载体 | 观察指标 |
|---|---|---|
| IC | 股权激励行权条件、提成斜率 | 绩效敏感度、相对绩效条款 |
| IR | 签字费、保底、对赌入场估值 | 人才流失率、融资是否谈崩 |
| 信息租金 | 高类型「信息费」 | 菜单价差、优质供应商溢价 |
| 代理成本 | 次优努力的价值损失 | 监控费、剩余损失估算 |
| 有限责任 | 工资非负、期权有限亏损 | 是否出现「赌徒」行为 |

中国语境：证监会《上市公司股权激励管理办法》（2016 施行，2025 年修正）把激励对象、资金来源、披露与处罚写入部门规章——这是把 IC 工具关进合规笼子。【事实】

拟上市对赌：监管要求原则上清理，同时满足「发行人非当事人、不导致控制权变化、不与市值挂钩、不严重损持续经营/投资者权益」等条件可不清理。【事实】【待验证：具体表述以最新审核问答为准】

# 关键问题清单

:::details Q1. IC 和 IR 哪个更常被忽视？
实务里常只谈「给够钱」（IR），不谈「偏离够不够疼」（IC）。【分析】
:::

:::details Q2. 为什么完全信息没有代理成本？
行动可写入合同并强制执行，只需满足 IR 的固定支付。【事实】
:::

:::details Q3. 信息租金和代理成本是一回事吗？
不是。前者来自隐藏类型（筛选），后者来自隐藏行动的风险/激励成本。【事实】
:::

:::details Q4. 何时该用固定工资？
噪声极大、多任务难测、或协作重于个人产出时。【分析】
:::

:::details Q5. 股权激励一定缓解代理问题吗？
提供 IC，但凸支付可能加剧风险转移；且受办法与信披约束。【分析】
:::

:::details Q6. 对赌是不是完美 IC？
是强力 IC，但法域可实施性受限；市值挂钩对上市公司路径尤敏感。【事实】
:::

:::details Q7. 一阶方法失效怎么办？
改用有限行动的 Grossman–Hart 程序，或验证 MLRP/CDFC。【事实】
:::

:::details Q8. 委托人也能有私人信息吗？
能，变成信号传递或知情委托人问题，骨架仍要 IC（对双方）。【分析】
:::

:::details Q9. 团队道德风险有何特殊？
免费搭车；相对绩效与拆分任务是常见解药。【事实】
:::

:::details Q10. 学完下一步读什么？
Bolton–Dewatripont《Contract Theory》；或本队列的道德风险 / 逆向选择专册。【分析】
:::
