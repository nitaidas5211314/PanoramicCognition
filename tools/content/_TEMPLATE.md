# 这个领域到底是什么

正文用标准 Markdown。**加粗**、*斜体*、`行内代码`、[链接](https://example.com)、列表、引用都能用。

### 更深一层（渲染为 h4）

来源标记这样写，会自动转成彩色标签：这是【事实】，这是【推论】，这是【假设】，这是【待验证】，这是【分析】。

表格会被自动包进 `.tw` 容器（窄屏可横向滚动），首列自动加 `class="k"`。

## 容器语法

### 提示框
```
:::note blue 小标题
内容，支持 Markdown。
:::
```
颜色可选 `blue` / `red` / `amber` / `green` / `purple` / `teal`。

### 卡片网格
```
:::cards g3
### 第一张卡
内容

### 第二张卡 {.danger}
内容

### 第三张卡 {.accent}
内容
:::
```
`g3` 可选 `g2` / `g3` / `g4`；`{.danger}` 这类后缀是卡片配色（`accent` / `warn` / `danger`）。

### 折叠卡
```
:::details 点击展开标题
里面藏起来的内容。
:::
```

### Tab 面板
```
:::tabs
@@选项 A
A 的内容

@@选项 B
B 的内容
:::
```

### 原样注入（SVG / 交互工具 / 自定义 HTML）
```
:::raw
<svg viewBox="0 0 680 300">…</svg>
:::
```
`raw` 块内的内容**不做任何转换**直接嵌入 HTML 版；在 MD 版中按 `md_raw` 设置处理（默认替换为一行提示）。

> **页脚的耗时字段是自动的**：`生成于 2026-09-16 · 耗时 36 分 · 数据截至 2026 年 9 月`。
> 数值由 `build.py` 读 `state.json` 里 `queue.py` 记录的运行时长算出，不要手写、不要手改 `reports/`。

**主题专属 JavaScript**：写在 front matter 的 `theme_js_file` 指向的 `.js` 文件里，构建时注入页面末尾的独立 `<script>`。它和页面通用脚本（进度条 / 导航高亮 / Tab 切换）互相隔离，不会冲突。
