# 一句话理解

美债只做三件事：**为美国联邦政府融资、为全球资产定价提供「无信用风险」基准利率、把利率/通胀/财政预期打包成可交易的价格**。

「无风险」指的是**美国政府违约概率极低**（【事实】美元储备货币地位 + 国内法币计价），**不是**价格不会跌——2022–2023 年 10 年期国债曾从收益率 1% 附近飙升至 5% 附近，价格跌幅超过 **20%**【待验证·市场回顾】。**无违约 ≠ 无波动**。

> 伯南克（2015）：「长期利率反映的是人们对未来短期利率路径的预期，加上期限溢价。」【引用】——美债收益率是**预期 + 风险补偿**的混合体，不是单一「政策利率」。

它的稀缺性不在背品种（Bill/Note/Bond/TIPS），而在**三条链同时读**：财政供给链（赤字→发债→吸走流动性）、货币政策链（Fed 持仓→QT/QE→期限溢价）、全球定价链（10Y 是全球 NPV 的分母）。

# 这个领域到底是什么

## 一句话边界

美债研究的是**美国财政部发行的、以美元计价的政府债务证券**——如何在一级/二级市场定价、被谁持有、如何影响全球利率与汇率。核心问题是：**给定财政路径与货币政策，收益率曲线各点由什么分解？持有各期限的真实回报来自哪里？**

**它最容易被误读的地方**：把「避险资产」当成「只涨不跌」——高通胀、加息周期里，长债是**利率风险的集中容器**。

## 用 15 个问题划定边界

| 问题 | 答案 |
|---|---|
| 研究什么 | 品种结构、拍卖机制、收益率曲线、持有者结构、与 Fed/财政的互动 |
| 边界在哪 | 聚焦美国国债；公司债、MBS 是信用/ prepay 风险，机制不同 |
| 核心对象 | Bills（≤1Y）、Notes（2–10Y）、Bonds（20–30Y）、TIPS、FRN |
| 参与者 | 财政部（发行）、Fed（持有/QT）、一级交易商、共同基金、外国官方、家庭 |
| 核心变量 | 收益率、久期、期限溢价、盈亏平衡通胀、拍卖 tail、债务上限 |
| 可观察 | H.15 常数期限收益率、MSPD 月度存量、拍卖结果、Fed H.4.1 持仓 |
| 不可观察但可推断 | 期限溢价、中性利率 r*、外国私人需求弹性 |
| 谁影响谁 | 赤字↑→供给↑→收益率↑（ceteris paribus）；Fed 缩表→边际买家减少 |
| 确定因果 | 票息固定→利率↑→价格↓（数学恒等）；实际利率≈名义−通胀预期（费雪近似） |
| 只是相关 | 「收益率倒挂」与「衰退」统计相关，单次预测力有限 |
| 表层现象 | 「10Y 破 5%」头条、债务上限闹剧、拍卖「尾部」走阔 |
| 底层机制 | 跨期套利、Preferred Habitat、财政主导（Fiscal Dominance） |
| 反馈 | 高利率→利息支出↑→赤字↑→更多发债→利率进一步承压 |
| 时间延迟 | 存量债务加权成本滞后 3–7 年才完全反映当前高利率 |
| 正负反馈 | 债务螺旋（正反馈）；Flight-to-quality 买盘（负反馈缓冲） |

# 为什么值得研究

## 四个理由

:::cards g2
### 它是全球资产的「分母」
10 年期美债收益率是股权 DCF、房产 cap rate、新兴市场主权债 spread 的共同参照。2026 年 9 月 10Y 约 **4.78%**、30Y 约 **5.24%**【事实·Fed H.15, 2026-09-11】——处于 2010 年以来极高分位【分析·新华财经 2026-09-10】。

### 它连接美国内政与全球金融
外国官方持有约 **$7.6 万亿** 非市场类 + 公众持有 **$32.4 万亿** 市场类【事实·MSPD 2026-08-31】；Fed 仍持 **$4.55 万亿** 国债【事实·H.4.1】。任何一方减持都改变边际定价。

### 它把「宏观叙事」变成可交易价格
通胀、增长、财政、地缘——最终都投影到曲线形状。读美债 = 读**市场版的宏观情景加权**。

### 它训练「利率风险 ≠ 信用风险」
散户常混淆「国债安全」与「债券基金不会亏」——久期 8 的 10Y 债，利率升 **100bp** 价格约跌 **7.9%**（见工具 1 默认刻度）。这是 2026 年仍须牢记的一课。
:::

:::note amber 一句话定性
美债研究不是「猜美联储下一步」，而是**分解收益率、匹配负债期限、识别财政-货币-全球的反馈环**。
:::

# 核心概念地图

| 概念 | 一句话 | 连到谁 |
|---|---|---|
| **收益率 y** | 使未来现金流现值等于价格的折现率 | 价格、久期、Fed 路径 |
| **修正久期** | 利率升 1% 价格约跌 ModDur% | 利率风险量化 |
| **期限溢价 TP** | 持有长债相对滚动短债的额外补偿 | 供给、Fed 持仓、通胀不确定性 |
| **盈亏平衡通胀** | 名义 − TIPS 收益率 | 通胀预期 + 流动性溢价 |
| **实际利率** | 名义 − 预期通胀 | 全球资产估值分母 |
| **SOMA 持仓** | Fed 系统公开市场账户国债 | QE/QT 边际需求 |
| **债务上限** | 法定借款总额 cap | 政治风险、TGA 波动 |
| **Primary Dealer** | 必须参与拍卖并做市的一级交易商 | 拍卖 tail、传导摩擦 |

:::note blue 跨域同构
**久期免疫 ↔ 负债匹配**：养老金 ALM 与银行利率风险监管，本质都是「资产 ModDur ≈ 负债 ModDur」。**期限溢价 ↔ 保险溢价**：承担「利率路径不确定」换取额外收益，类似卖波动。**债务螺旋 ↔ 复利 r>g**：与宏观债务动态同一方程，只是对象换成美国国债存量。
:::

# 核心参与者

| 参与者 | 角色 | 激励/约束 |
|---|---|---|
| **美国财政部** | 发行人、决定拍卖节奏 | 融资成本最小化 vs 期限结构稳定 |
| **美联储** | 持有者、政策利率、QT | 物价/就业目标；缩表不扰动市场 |
| **一级交易商** | 拍卖承销、做市 | 库存成本、资本规则、客户订单 |
| **共同基金/ETF** | 最大私人持有者类别之一 | 相对指数、Reach for duration【分析】 |
| **外国官方（中日等）** | 储备管理 | 安全+流动性 vs 地缘与汇率 |
| **对冲基金/RV 基金** | 曲线交易、基差 | 杠杆、抵押品成本 |
| **家庭/退休账户** | 间接持有 | 「安全」叙事、对波动认知不足 |
| **中国等储备国** | 最大外国债权人之一【待验证】 | 多元化 vs 可替代性有限 |

> 【事实】2026 年 8 月公众持有市场类国债 **$32.41 万亿**，政府账户（含社保等）**$8.11 万亿**，合计名义债务 **$40.18 万亿**（MSPD）。

# 隐藏关系

- **名义 vs 实际**：10Y 4.78% 里约 2.17% 是通胀补偿【事实·BEI】——「高名义」不等于「高真实回报」。
- **无信用风险 vs 有利率风险**：零违约概率的证券仍可有 **−20%** 级别的价格回撤（2022–2023【待验证】）。
- **Fed 不持有时谁接**：QT 把 **$4.55T** 存量重新抛给私人部门【事实】——边际定价从「政策主导」回到「市场主导」。
- **外国减持 vs 美元升值**：长端实际利率上行常伴美元强【分析·新华财经】——「卖美债」与「美元需求」可并存。
- **Bill 占比上升**：2026-08 Bills **$7.25T** 占市场类约 **23%**【推论】——财政部缩短久期 = 把利率风险转嫁给未来再融资。
- **Duration 线性近似失效**：大幅利率变动需 convexity 修正【分析·Atlanta Fed 1990s 文献】——工具 1 的一阶公式在 ±100bp 内可靠，±300bp 需二阶。

> 【推论】隐藏关系的共同形状：**流量（拍卖）与存量（加权成本）、名义与实际、国内财政与全球贴现率**三层常被混为一谈。

# 常见认知陷阱

:::details 把「国债安全」当成「债券基金不会跌」
2022–2023 年 AGG/TLT 类长期国债 ETF 最大回撤可观【待验证】——**零信用风险 ≠ 零价格波动**。
:::

:::details 把 10Y 收益率当成「美联储利率」
10Y 含 **预期路径 + 期限溢价**；2026 长端高位主要由**长期实际利率**推动，而非单纯 Fed 加息【分析·新华财经】。
:::

:::details 认为「收益率越高越该买长债」
高 y 常伴随 **Δy>0 的价格下跌**——须算 carry 是否覆盖久期损失（工具 4）。默认：3M **3.91%** vs 10Y **4.78%**、12 个月、Δy=0 → 长端仅 +**0.87pp** 超额。
:::

:::details 忽视 convexity 与曲线非平行移动
Modified duration 在 ±100bp 内较准；Atlanta Fed 经典文指出**非平行移动**可让「对冲组合」仍暴露风险【分析】。
:::

:::details 「外国抛售美债 → 美国立刻崩溃」
官方减持是渐进的；美元储备货币地位与替代资产稀缺使调整**慢且不完全**【分析】——但边际上推升期限溢价仍可能。
:::

:::details 把 TIPS 当「一定跑赢 CPI」
TIPS 有**流动性溢价**；BEI 2.17% 含风险溢价，不等于 CPI 点预测【推论】。
:::

:::details 债务上限 = 违约
通常是**政治博弈 + 非常规措施（暂停、减支）**——扰动 TGA 与 Bill 利率，但「技术性违约」与「重组违约」不同【分析】。
:::

:::details 单看名义赤字忽略净利息
FY2025 净利息首超 **$1T**【事实】——即使 primary deficit 收敛，利息仍可能推升总赤字。
:::

:::details 「倒挂必衰退」
倒挂是**统计信号**非因果；单次预测须对照「随机猜衰退」基准——命中率未必显著超额【推论】。
:::

:::details 用到期收益率当「持有到期回报」
若再投资利率变化、提前卖出，**实现回报 ≠ YTM**——尤其长债。
:::

:::details 忽视 Reach for Duration
Fed 2024 研究：共同基金用**国债期货加久期**匹配指数，并非传统对冲【分析·FEDS 2024-039】——指数投资者也在放大波动。
:::

:::details 把 CMT _yield 当「某只债券成交价」
H.15 是**插值常数期限**，基于 OTC **指示性报价**非逐笔成交【事实·Treasury】。
:::

# 反事实模拟

:::tabs
@@若 Fed 从未 QE
【推论】2020 危机后长端收益率或更高、财政融资更贵；但 2022 通胀后「长债巨亏」幅度可能更小——**政策干预交换了时间轴上的痛苦位置**。
@@若 2025 未提高债务上限 $5T
【假设】2026 年或重演债务上限僵局，Bill 利率 spike、TGA 耗尽——「技术性风险」上升，但**市场类存量未必立刻下降**。
@@若 外国官方 5 年减持 $3T
【假设】期限溢价显著上升，10Y 可能升 **50–100bp**（区间依赖私人承接）【假设·模型敏感】——美元未必崩，但**融资成本结构性上移**。
:::

# 30 分钟最小实践

**目标**：今天就能做、成本≈0、产出可验证。

**① 久期敏感度（8 分钟）**
工具 1：期限 **10 年**、票息 **4.5%**、YTM **4.78%**、冲击 **+100bp** → 修正久期 **7.95**、价格约 **−7.9%**。写下：若你的「安全」债券基金 effective duration≈6，利率升 100bp 约 **−6%**（一阶近似）。

**② 实际利率（7 分钟）**
工具 2：名义 **4.78%**、盈亏平衡 **2.17%** → 实际 **2.61%**。对比：若 BEI 升至 2.5% 而名义不变，实际降至 **2.28%**——**通胀预期上行吞噬真实回报**。

**③ 利息螺旋（8 分钟）**
工具 3：公众债务 **$32.4T**、平均利率 **4.2%**、初级赤字 **4% GDP** → 年利息约 **$1.36T**、占 GDP **4.8%**。写下：FY2025 净利息已超 **$1T**【事实】——「赤字=新借」之外还有「旧债利息自动涨」。

**④ 曲线 carry（7 分钟）**
工具 4：3M **3.91%**、10Y **4.78%**、12 个月、Δy=**0** → 短端 **+3.91%**、长端 **+4.78%**、超额 **+0.87pp**。把 Δy 调到 **+100bp** → 长端约 **−3.17%**、**跑输短端**——** steep 曲线不等于该买长债**。

:::note amber 验收标准
你能向别人解释「2026 年 10Y 接近 5% 但买长债仍可能亏」而不只说「国债安全」——就算入门。
:::

# 10 个核心模型

| # | 模型 | 一句话 | 跨域同构 |
|---|---|---|---|
| 1 | **贴现现金流** | P=∑CF/(1+y)^t | ↔ DCF 估值 ↔ 现值思想 |
| 2 | **久期/凸性** | ΔP/P≈−D·Δy+½C·(Δy)² | ↔ 弹性 ↔ 泰勒展开 |
| 3 | **费雪方程** | 名义≈实际+通胀 | ↔ 宏观费雪 ↔ 真实回报 |
| 4 | **期限结构** | 远期=预期短期利率+溢价 | ↔ 期货曲线 ↔ 预期假设 |
| 5 | **Preferred Habitat** | 不同投资者偏不同期限 | ↔ 细分市场 ↔ 生态位 |
| 6 | **债务动态** | Δd≈(r−g)d+赤字 | ↔ 财政可持续性 ↔ 复利 |
| 7 | **QT 再分配** | 央行存量→私人边际 | ↔ 资产再定价 ↔ 私有化边际 |
| 8 | **拍卖经济学** | 荷兰式+dealer 库存 | ↔ 机制设计 ↔ 流动性供给 |
| 9 | **全球金融周期** | 美长端→跨境资本 | ↔ 主中心溢出 ↔ 引力模型 |
| 10 | **Fiscal Dominance** | 财政约束绑架货币 | ↔ 财政货币化 ↔ 三元冲突 |
