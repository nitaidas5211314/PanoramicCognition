# 一句话理解

**坟包收割**是南京大学商学院安同良教授团队对 A 股量化交易一种典型形态的命名：先用算法拉出「放量突破」诱散户追高，再以每日 1%–3% 的阴跌消磨耐心，最后在低位接回筹码——K 线呈**尖顶、连阴、平底**，形似坟包。【分析】

这份拆解的价值不在于给你一个「庄家名单」，而在于把一件散户体感极强、却难以言说的痛苦，翻译成**可检验的三段式机制**：选标的 → 造信号 → 慢出货。它的锋利之处是解释力；它的危险之处是**把研究团队的归纳当成法庭判决**——量化行业对此有强烈反驳，监管口径与学术建议也尚未完全落地。

# 这个领域到底是什么

## 边界：研究什么、不研究什么

| 研究 | 不研究 |
|---|---|
| 「坟包」形态的**阶段划分**与**可观测特征** | 某只股票明天会不会涨 |
| 量化与散户之间的**结构不对称**（速度、工具、信息） | 某个具体机构是否「作恶」 |
| 安同良团队提出的**监管建议**及其与现行规则的差距 | 消灭量化或全面禁止程序化交易 |
| 散户如何**识别风险信号**、设定退出规则 | 保证你靠「反量化」稳定盈利 |

## 十五个问题：先建世界模型

| 问题 | 答案 |
|---|---|
| 研究什么 | 量化机构如何利用微观结构优势，在特定标的上完成「高卖低买」闭环 |
| 边界在哪 | 到「可观测的价量行为」为止；动机与合规性需另证 |
| 核心对象 | 坟包形态（尖顶—阴跌—平底）、散户持仓结构、程序化订单流 |
| 参与者 | 量化私募、券商自营、散户、做市商、交易所、监管层 |
| 核心变量 | 散户持仓占比、日换手率、申报速率、融券余额、板块热度 |
| 可观察 | K 线形态、成交量放大、均线排列、每日涨跌幅分布、龙虎榜 |
| 不可观察但可推断 | 算法参数、真实净头寸变化、多账户协同 |
| 谁影响谁 | 订单流 → 价格 → 技术信号 → 散户行为 → 流动性 → 再影响价格 |
| 确定因果 | 监管降频/限通道 → 申报速率下降 → 部分策略失效【事实·政策】 |
| 只是相关 | 「突破后阴跌」与「量化主导」——形态可有多重解释 |
| 表层现象 | 放量突破、均线多头、连阴不破新低 |
| 底层机制 | 流动性供给/消耗的不对称 + 行为金融里的「处置效应」 |
| 反馈 | 散户亏损 → 减少参与 → 量化转向其他标的（负反馈）；成功案例吸引模仿（正反馈） |
| 时间延迟 | 从造信号到出货完成，团队描述为**二三十个交易日**量级 |
| 正负反馈 | 阴跌阶段：恐慌加深 → 更多割肉（正反馈）；监管介入 → 策略降温（负反馈） |

## 与相邻概念的区别

| 概念 | 问什么 | 与坟包的关系 |
|---|---|---|
| 威科夫派发 | 大资金是否在出货？ | 都描述「诱多后下跌」，威科夫更慢、更依赖区间与量价 |
| 技术分析突破 | 突破前高是否有效？ | 坟包叙事把「假突破」当成量化刻意制造 |
| 有效市场假说 | 价格是否已反映信息？ | 若坟包普遍存在，则技术信号含系统性可剥削成分 |
| 博弈论（凯尔模型） | 收益从谁手里来？ | 坟包是「噪声交易者」被针对性收割的一种故事化版本 |

# 为什么值得研究

## 四个理由

:::cards g2
### 它把「无形的手」翻译成可复盘的三段式
散户常说「被量化收割了」，但说不清机制。安同良团队把过程拆成**选流动性好的散户票 → 造突破信号 → 阴跌出货**，让讨论从情绪进入结构。【分析】

### 它连接了微观行为与宏观公平议题
2026 年证监会主席吴清提出「突出公平性，深化细化高频量化监管」【事实】——坟包叙事正好落在「速度优势是否构成不公平」这一监管主轴上。

### 它逼你对数字保持警惕
团队引用的「45 家百亿量化 2025 年平均收益 37.6%、散户人均亏 2.1 万元」来自媒体报道与第三方平台汇总【待验证】——**二手数字必须标待验证**，否则你会把叙事里的震撼当成证据。

### 它给出可操作的散户防御框架
即便不认同全部因果，你仍可学会：**突破后不追、阴跌设时限止损、把「每日小跌」当成出货信号而非「洗盘」**——这是零成本可验证的行为改变。
:::

## 也必须先说清楚：争议在哪里

- **量化行业的反驳**：许多策略是市场中性、提供流动性，不能把亏损简单归因于「收割」。【分析】
- **因果识别困难**：同样形态可能来自基本面恶化、板块轮动或散户踩踏，未必是单一主体「做局」。【推论】
- **政策建议≠现行法律**：「每秒 15 笔」高频门槛目前仍是**建议**，交易所现行标准为**每秒 300 笔**【事实】。

:::note amber 一句话定性
坟包收割是一套**高质量的风险叙事 + 中等质量的因果证据**。学它的方式，是学「怎么问对问题」，而不是学「怎么找坏人」。
:::

# 核心概念地图

## 坟包三阶段

:::cards g3
### 阶段一 · 造信号（尖顶）
算法集中买入，拉出放量突破。散户熟悉的「均线多头排列」「突破前高」同时亮起。【分析】

### 阶段二 · 阴跌出货（坟身）
停止买入，小单高频卖出。每日跌 1%–3%，持续 20–30 天——**不暴跌**，避免触发恐慌性监管关注。【分析】

### 阶段三 · 回补（平底）
散户割肉后，量化在低位接回筹码，等待下一轮循环。【分析】
:::

## 团队归纳的另外两套手法（对照用）

| 手法 | 核心机制 | 与坟包的关系 |
|---|---|---|
| 逐浪抱团 | 同质化模型追逐同一热点，助涨后同步止损 | 常出现在「造信号」之前，放大突破可信度 |
| 精准狙击 | 涨停诱多 + 融券砸盘 + T+1 锁仓 | 更短、更狠；坟包是「慢刀」版本 |

## 跨域同构

| 本领域 | 同构领域 | 共享结构 |
|---|---|---|
| 坟包阴跌 | 挤兑/银行慢跑路 | 每日小额流出，避免触发挤兑阈值 |
| 造突破信号 | 广告漏斗 A/B 测试 | 先制造可点击信号，再转化（这里是反向转化） |
| 非对称收割 | 捕食者—猎物模型 | 速度差决定捕获率，而非绝对体量 |
| 监管降频 | 限速/碳排放配额 | 把外部性内部化，改变策略可行域 |

# 核心变量

| 变量 | 定义 | 坟包叙事中的角色 | 数据来源性质 |
|---|---|---|---|
| 散户持仓占比 | 流通股中散户持有比例 | 高 → 更易被选为「收割标的」 | 【待验证】需股东户数/持股结构 |
| 日跌幅分布 | 连续小阴线的均值与方差 | 1%–3%/日 × 20–30 天为典型区间 | 【分析】形态描述 |
| 申报速率 | 每秒申报+撤单笔数 | ≥300 认定为高频【事实】 | 交易所《实施细则》 |
| 量化成交占比 | 量化订单/全市场成交 | 全市场 30%–40%，小盘超 50%【待验证】 | 第三方平台 |
| 融券余额 | 可借券规模 | 「精准狙击」依赖；坟包以现货为主 | 【事实】交易所披露 |
| 突破后 5 日收益 | 追突破策略的短期表现 | 检验「信号是否系统性吃亏」 | 【推论】需自建回测 |

## 确定因果 vs 只是相关

| 关系 | 类型 | 说明 |
|---|---|---|
| 高速通道清理 → 部分策略降速 | 因果【事实】 | 2026 年上交所清理量化专属高速通道 |
| 突破形态 → 后续阴跌 | 相关 | 也可能是基本面恶化或板块退潮 |
| 量化盈利 ↑、散户亏损 ↑ | 相关 | 零和视角简化；忽略机构间互搏与β |

# 隐藏关系

1. **好公司也可能跌**：团队指出，基本面未坏但散户持仓多的股票仍可能持续下跌——**价格与价值短期脱钩**。【分析】
2. **差公司可能被推涨**：热点题材下，量化「逐浪」可把弱势股短期推高——与坟包「选标」逻辑同一生态。【分析】
3. **「洗盘」叙事是散户端的共谋**：阴跌阶段最需要抵抗的不是量化，而是你自己脑中的故事生成器。
4. **监管套利**：现行高频门槛 300 笔/秒，机构可卡在 299 笔【分析】——规则边界即战场。
5. **跨域同构：温水煮青蛙**：每日 2% 跌 25 天累计约 **39.7%**（见下节计算器），远低于单日跌停的冲击，但结局一样。

# 常见认知陷阱

:::details 1. 「突破就是主升浪」
技术突破在 A 股被大量程序化监控。突破当日追入，相当于自愿进入博弈的**第二阶段**。【推论】
:::

:::details 2. 「每天只跌一点，是洗盘」
团队描述的核心正是**慢跌消磨**。把 -2%/日读成洗盘，是坟包最需要的散户合作。【分析】
:::

:::details 3. 「量化赚了所以我亏的」
盈亏零和是简化。你还可能输给β、行业、自己的换手。【推论】
:::

:::details 4. 把媒体报道数字当铁案
37.6%、2.1 万、1.8 万亿均为二手汇总【待验证】，需查原始口径。
:::

:::details 5. 「好公司不会阴跌」
团队反例：基本面好但散户多的股票仍可能跌。【分析】
:::

:::details 6. 追求「抓量化反向」
没有稳定公开信号证明「反做量化」长期有效。【假设】
:::

:::details 7. 忽视交易成本
即使方向对，高频换手也会让散户净收益更差。【事实】
:::

:::details 8. 把政策建议当已落地
15 笔/秒目前非现行标准；300 笔/秒仍有效【事实】。
:::

:::details 9. 幸存者偏差看量化收益
报道的 45 家百亿私募全盈利，未包含清算机构。【待验证】
:::

:::details 10. 仓位决定解读
套牢后更容易把阴跌读成「暂时调整」——L9 层陷阱。【分析】
:::

:::details 11. 过度拟合历史坟包
事后 K 线像坟包不等于当时可识别。【推论】
:::

:::details 12. 忽视 T+1 与涨停制度
制度本身改变博弈结构，不能照搬美股微观结构结论。【事实】
:::

# 反事实模拟

:::tabs
@@若 2026 年高频门槛降至 15 笔/秒
许多卡 299 笔的策略需重构或承担更高费用；坟包「小单高频卖」段成本上升，形态频率可能下降。【推论】但中低频策略仍可能存在。
@@若 散户全面指数化、几乎不追突破
量化「造信号」段的对手盘减少，策略容量下降，可能转向其他市场或资产类别。【推论】
@@若 完全禁止程序化交易
流动性下降、冲击成本上升；「一刀切」非监管层主张——吴清强调的是**公平与细化**，不是消灭。【分析】田轩等学者亦认为需规范发展【分析】。
@@若 坟包只是事后叙事、并无系统操纵
你的防御规则仍然有效：不追、阴跌止损、对照基准——**好规则不依赖坏因果**。【推论】
:::

# 30 分钟最小实践

**目标**：用真实自选（或最近关注的一只股），完成一份「坟包风险体检表」。

1. **5 分钟**：打开日 K，标最近 60 日是否出现「尖顶 + 连阴 ≥10 日 + 平底」组合。
2. **5 分钟**：查股东户数/融资余额变化（交易所或行情软件）。
3. **5 分钟**：用本手册阴跌计算器，输入你认为的日均跌幅与天数，看累计回撤是否超过你的承受力。
4. **10 分钟**：写下三条规则——(a) 何种突破不追；(b) 连阴几日必须减仓；(c) 什么证据出现则承认「读错了」。
5. **5 分钟**：把 37.6%、2.1 万等数字标成【待验证】，写一句「我还需要查的原始来源」。

**产出**：一张可拍照存档的体检表 + 三条可执行规则。**成本 ≈ 0**。
