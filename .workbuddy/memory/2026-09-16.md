## 给引擎加「批量执行」（queue.py batch）

用户要「一次性把 queue.md 里所有待执行的全加到任务里，完成一个立刻跑下一个」。约定：跑到上下文上限自动停、可续跑；失败跳过继续；清单逐条建成会话 todo。

### 新增命令
- `queue.py batch [--limit N] [--json] [--dry-run] [--stale MIN] [--no-adopt]` —— 批量清单，默认取**全部** pending，并把批次落进 `state.json.batch`（id/started/limit/size/slugs）。
- `queue.py batch --summary` —— 收尾汇报：本批逐项状态 + 累计耗时 + 还剩几个。
- `queue.py next --skip-failed` —— 批量循环内取任务，只领 pending。
- `queue.py list` 顶部多一行「当前批次 x/y 已完成」。

### 顺手修掉的两个真实缺陷（都是这次设计批量时暴露的）
1. **失败项会让队列死锁**：`next` 默认把 `failed` 也算可领取，某项失败后它仍在队首 → `next` 反复捞回同一项，`remaining` 永不动。批量循环因此强制用 `--skip-failed`（普通 `next` 行为保持向后兼容）。
2. **僵尸 `running` 没有出口**：`next` 只领 pending/failed，中断留下的「进行中」再也没人跑。`batch` 现在自动接管 —— `started` 早于 `--stale`（默认 120 分钟 = 2× 推荐间隔）的 running 判定为中断、reset 回 pending 并排进本批；`started` 很新的 running 不抢，避免和定时任务撞车。
   - 顺带修正了 SKILL.md §8.2 里「进行中主题会被重新分配」这句失实描述。

### 测试
10 项待办上验证：dry-run 不落盘、limit 截断与「还剩 N 个」、失败后 next 正确跳到下一项（对照普通 next 会捞回失败项）、僵尸接管、空队列返回 `__QUEUE_EMPTY__`（退出码 3）。测完已从备份还原 `state.json`（仅 `updated` 时间戳变化）。

### 文档
- README 新增「批量跑（一次把待办全跑完）」小节 + 坑表两条。
- SKILL.md 新增 §8.6 批量执行（含循环体与四条硬规则），并修正 §8.1/§8.2 的失实描述。

### 设计取舍
批量**不做成定时任务**：定时任务的间隔是按单主题最长耗时算的，连跑会让间隔规则失效。批量是「人在场时的一次性动作」，无人值守仍走原来的每小时定时任务（`a94594e5...`，当前 PAUSED）。

### 选题定位
《高勝算決策》= Annie Duke《Thinking in Bets: Making Smarter Decisions When You Don't Have All the Facts》(2018)，采實文化繁體版；簡體版《對賭》中信 2018 年 12 月，譯者李光輝。核心概念：resulting（結果論）、truthseeking pod、把信念當賭注、10-10-10、backcasting、premortem、尤利西斯合約、CUDOS。

**與第 1 個主題的分工**：《Quit》答「什麼時候該停」，《Thinking in Bets》答「你憑什麼判斷該不該停」——前者是行動規則，後者是計量儀器。手冊裡明確寫了這層關係（01 節）。

### 本手冊的核心論點（書裡沒給）
杜克說「不要用結果評判決策」，但從沒算過一次結果能告訴你多少。手冊把它算出來，四個模型：
1. **結果的信噪比**：好決策 60% / 壞決策 40% 時，單次結果信息量僅 **±10pp**；n=10 的判別準確率 **73.3%**；判到 90% 需 **41 次**、95% 需 **67 次**。要證明「比瞎猜強 5pp」需 **620 次**獨立決策（精確二項檢定，單側 α=.05、功效 .80）。
2. **賭注校準台**：Brier 0.25 = 「永遠說 50%」的基準。說 90% 實際 62% → **0.3140**，比沉默更差；每注期望 **−31.1%**。實際命中率 a 固定時，報 c=a 嚴格最優（二次懲罰）。
3. **求真小組的定價**：P(群體正確) = (1−ρ)·孔多塞 + ρ·單人。7 人、個人 60%：獨立 71.02%，ρ=0.3 掉到 67.71%（縮水 30%），只值 **5 個獨立的人**。ρ=1 時多人小組等於一個人。
4. **心理時間旅行**：β=0.7、δ=0.98 時，10 分鐘 / 10 個月 / 10 年的折現因子 0.700 / 0.688 / 0.572；等一年的隱式年化貼現率 **45.8%**；**被短視否掉的長期正確專案比例恰好 = 1 − β = 30%**（精確恆等式）。
