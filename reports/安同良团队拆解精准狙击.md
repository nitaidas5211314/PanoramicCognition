## 00 · 一句话理解

**精准狙击**是南京大学商学院安同良教授团队对 A 股量化交易第三种典型形态的命名：利用**速度、订单流与信息优势**，精准定位散户的**止损位、支撑位与挂单密集区**，先快速砸穿关键价位触发恐慌抛售，再在低位接回筹码——时间尺度比「坟包收割」短得多，往往集中在**涨停诱多日或关键均线失守日**。【分析】

与慢刀阴跌、板块级逐浪不同，精准狙击是**快刀**：借 T+1 锁仓与融券工具放大不对称。学它的方式，是学「怎么识别关键价位风险」，而不是学「怎么猜庄家底牌」。

## 01 · 这个领域到底是什么

### 边界：研究什么、不研究什么

| 研究 | 不研究 |
|---|---|
| 「砸穿支撑 → 止损连锁 → 低位接回」的**可观测阶段** | 某只股票明天会不会涨停 |
| 速度/融券/T+1 带来的**结构不对称** | 某个席位是否「恶意做局」 |
| 安同良团队**五维纠偏**中与限空、降频相关的建议 | 消灭量化或全面禁止程序化 |
| 散户如何**设止损、避追涨停、读融券** | 保证靠「反量化」稳定盈利 |

### 十五个问题：先建世界模型

| 问题 | 答案 |
|---|---|
| 研究什么 | 量化如何利用微观结构在关键价位完成「触发—收割—回补」闭环 |
| 边界在哪 | 到订单簿/价量/制度可观测层；个体动机与合规需另证 |
| 核心对象 | 支撑位、止损簇、挂单密集区、涨停诱多、T+1 锁仓 |
| 参与者 | 量化私募、融券出借方、散户、券商、交易所、监管层 |
| 核心变量 | 申报速率、融券余额、散户止损分布、涨跌停距离、通道延迟 |
| 可观察 | 关键价位放量跌破、融券余额异动、龙虎榜、分时大单 |
| 不可观察但可推断 | 算法识别的止损地图、多账户协同、真实净空头 |
| 谁影响谁 | 订单流 → 价格击穿 → 止损触发 → 流动性枯竭 → 再下压价格 |
| 确定因果 | T+1 → 当日买入无法当日卖出【事实·制度】 |
| 只是相关 | 「跌破支撑后暴跌」与「量化狙击」——也可能是基本面利空 |
| 表层现象 | 涨停次日低开、支撑位放量长阴、盘口大单压单 |
| 底层机制 | 订单流不对称 + 止损规则同质 + 制度锁仓 |
| 反馈 | 止损触发 → 更多卖压（正反馈）；监管限空 → 融券砸盘成本上升（负反馈） |
| 时间延迟 | 击穿到连锁往往在**分钟至数日**；回补可在同周完成 |
| 正负反馈 | 散户追涨停 → 次日无法跑 → 隔夜敞口放大（制度正反馈） |

## 02 · 为什么值得研究

### 四个理由

#### 它把「无形的手」落到具体价位上
散户常说「刚设止损就被打掉」。团队把过程拆成**识别密集区 → 砸穿 → 接回**，让讨论从玄学进入订单流结构。【分析】

#### 它连接制度与微观优势
A 股 **T+1**、涨跌停、融券可得性——制度本身改变博弈可行域；2026 年监管层清理部分量化高速通道【事实】，直接冲击 L8 速度层。

#### 它逼你对「涨停追击胜率」做基准对照
μ=10%、σ=18%、**T=5 日**时随机做多基准胜率 **53.1%**——「5 日胜率 58%」的真实超额仅 **4.9 pp**（见 §20 漂移剥离器）。【推论·公式】

#### 它给出可操作的价位防御框架
即便不认同全部因果，仍可学会：**止损不设在众人都知道的位置、涨停日不追、查融券余额异动**——零成本可验证。

### 也必须先说清楚：争议在哪里

- **量化行业反驳**：跌破支撑可能来自基本面、板块退潮或散户踩踏，不能全部归因「狙击」。【分析】
- **订单流不可公开复现**：散户无法直接看到完整订单簿，「精准」程度难以第三方审计。【推论】
- **融券数据滞后**：交易所披露有延迟，「砸盘」与融券余额的因果难严格识别。【待验证】
- **政策建议≠现行法**：限空、15 笔/秒门槛仍是**建议**；高频认定仍为 **300 笔/秒**【事实】。

> **一句话定性**
>
> 精准狙击是**高质量的微观结构风险叙事 + 中等质量的因果证据**。价值在「识别关键价位陷阱」，不在「预测下一个涨停」。

## 04 · 核心概念地图

### 精准狙击三阶段

#### 阶段一 · 诱多（抬高锚点）
涨停或放量突破，吸引追涨、上移止损线。散户技术信号「完美」。【分析】

#### 阶段二 · 击穿（触发连锁）
快速砸穿支撑位或密集止损区。订单流优势使散户挂单被动成交。【分析】

#### 阶段三 · 接回（低位吸筹）
恐慌抛售后在低位接回筹码，等待下一轮循环。【分析】

### 团队归纳的三套手法（对照）

| 手法 | 时间尺度 | 核心机制 |
|---|---|---|
| **精准狙击** | 短（分钟至数日） | 诱多 → 砸穿止损簇 → 接回 |
| 坟包收割 | 长（20–30 日阴跌） | 假突破 → 慢出货 |
| 逐浪抱团 | 中（板块趋势） | 同质助涨 → 同步止损 |

### 跨域同构

| 本领域 | 同构领域 | 共享结构 |
|---|---|---|
| 止损连锁 | 多米诺骨牌 | 单点失效触发级联 |
| 砸穿支撑 | 堤坝溃口 | 小破口 → 流量集中 → 崩溃 |
| T+1 锁仓 | 期权隔夜 Gamma | 制度锁定风险敞口 |
| 融券放大 | 杠杆去杠杆 | 下跌触发强制平仓 |
| 精准靶向（安同良创新网络） | 枢纽节点打击 | 打击关键节点 → 网络功能瘫痪 |

## 08 · 隐藏关系

1. **止损越「标准」，越容易被针对**：均线、前低、整数关口是公共知识，也是公共靶子。【推论】
2. **涨停诱多与 T+1 是制度共谋**：不是某个恶庄单独设计，而是规则 + 行为叠加。【分析】
3. **融券是「狙击」叙事的关键放大器**：坟包以现货慢卖为主；狙击强调融券砸盘【分析】——但 2025 年后融券监管持续收紧【事实】。
4. **「洗盘」与「击穿」在 K 线上几乎一样**：区别在成交量结构与是否快速收回——事后才容易分。【推论】
5. **跨手法衔接**：逐浪退潮 → 坟包阴跌 → 或精准击穿关键支撑，同一标的可能在不同阶段切换手法。【分析】

## 14 · 常见认知陷阱

**▶ 1. 「涨停就是主升浪起点」**

涨停可能是诱多第一段。T+1 下你当日无法纠错。【分析】

**▶ 2. 「止损刚被打掉就是洗盘」**

团队叙事的核心正是**利用公共止损位**。洗盘与击穿事后才易分。【分析】

**▶ 3. 「量化赚了所以我亏的」**

零和是简化。你还可能输给β、行业、自己的换手。【推论】

**▶ 4. 把媒体报道数字当铁案**

37.6%、2.1 万、1.8 万亿均为二手汇总【待验证】。

**▶ 5. 「融券余额高一定有人做空我」**

余额上升可能是下跌后的借券需求，因果双向。【推论】

**▶ 6. 追求「反量化狙击」**

没有稳定公开信号证明有效。【假设】

**▶ 7. 忽视交易成本**

频繁追板让净收益更差。【事实】

**▶ 8. 把政策建议当已落地**

15 笔/秒、全面限空目前非现行标准。【事实】

**▶ 9. 止损设在人人皆知的位置**

整数关口、前低、20 日均线 — 公共靶子。【推论】

**▶ 10. 仓位决定解读**

套牢后更容易把击穿读成「暂时洗盘」。【分析】

**▶ 11. 只看日线不看分时**

狙击叙事强调**分钟级**订单流，日线会平滑掉关键过程。【推论】

**▶ 12. 忽视与坟包/逐浪的衔接**

同一标的可能在不同阶段切换手法。【分析】

## 20 · 反事实模拟

#### 若 2026 年全面限空量化融券

融券砸盘通道收窄，狙击叙事中的「放大器」减弱；现货快砸仍可能存在。【推论】

#### 若 取消 T+1 改 T+0

涨停追入可当日纠错，诱多段对手盘风险上升，狙击第一段成本增加。【推论】

#### 若 散户全面停止追涨停

诱多段缺乏对手盘，策略容量下降，量化可能转向其他手法或市场。【推论】

#### 若 狙击只是事后叙事、并无系统操纵

你的防御规则仍然有效：不追、止损错位、查融券——**好规则不依赖坏因果**。【推论】

## 22 · 30 分钟最小实践

**目标**：用真实自选（或最近关注的一只股），完成一份「精准狙击风险体检表」。

1. **5 分钟**：查近 20 日是否出现「涨停/突破 → 快速跌破关键支撑」组合。
2. **5 分钟**：查融券余额周变化（交易所披露）。
3. **5 分钟**：用击穿连锁计算器，输入你认为的追入溢价与击穿幅度，看总亏损是否超过承受力。
4. **10 分钟**：写下三条规则——(a) 何种涨停不追；(b) 止损如何「错位」；(c) 什么证据出现则承认「读错了」。
5. **5 分钟**：把 37.6%、2.1 万等数字标成【待验证】，写一句「我还需要查的原始来源」。

**产出**：一张可拍照存档的体检表 + 三条可执行规则。**成本 ≈ 0**。
